🔑 Token do GitHub

Necessário só para salvar ou apagar fichas no repositório. Para apenas visualizar (Painel do Mestre), não precisa de token, pois o repositório é público.

Nenhum token configurado neste navegador.
Como gerar seu token (leva 1 minuto):
  1. No GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em "Repository access", escolha Only select repositories e selecione hugomabinogi2-star/GMMRPG.
  3. Em "Permissions → Repository permissions", defina Contents: Read and write.
  4. Gere o token e cole aqui. Ele fica salvo só neste navegador (nunca é enviado a ninguém além do GitHub) — trate-o como uma senha e não o compartilhe no Discord.

🔗 Webhook do Discord

URL do Webhook do canal do Discord onde as rolagens, fichas salvas e mensagens da mesa devem ser espelhadas. Fica salva só neste navegador e é sempre a última que você salvar aqui.

Nenhum webhook configurado neste navegador.
Como pegar o link (leva 10 segundos):
  1. No Discord, abra o canal desejado e vá em Editar Canal → Integrações → Webhooks.
  2. Crie um novo webhook (ou use um já existente) e clique em Copiar URL do Webhook.
  3. Cole aqui e clique em "Salvar webhook". Ele fica guardado neste navegador e é sempre o último salvo — para parar de postar no Discord, apague o campo e clique em "Desativar".
