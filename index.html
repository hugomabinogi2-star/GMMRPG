🔑 Token do GitHub

Necessário só para salvar ou apagar fichas no repositório. Para apenas visualizar (Painel do Mestre), não precisa de token, pois o repositório é público.

Nenhum token configurado neste navegador.
Como gerar seu token (leva 1 minuto):
  1. No GitHub, vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em "Repository access", escolha Only select repositories e selecione hugomabinogi2-star/RPGGMM.
  3. Em "Permissions → Repository permissions", defina Contents: Read and write.
  4. Gere o token e cole aqui. Ele fica salvo só neste navegador (nunca é enviado a ninguém além do GitHub) — trate-o como uma senha e não o compartilhe no Discord.
